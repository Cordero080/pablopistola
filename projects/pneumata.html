PNEUMATA

Interactive 3D anatomical model — every human organ mapped to its hardware analog, with bidirectional spinal highlighting

GitHub

About

The human body and a computer are not metaphorically similar — they are architecturally isomorphic. The heart is a PSU. The spinal cord is a PCIe bus. The kidneys are a virtual memory manager. The immune system is an IDS with edge nodes, a SIEM, and a definition update engine.

Pneumata makes that argument visual and interactive. Every organ node in the model corresponds to a specific hardware component. Every spinal disc corresponds to a bus arbitration layer. The relationship is functional, not decorative — the same engineering problem solved twice, in different substrates, separated by 500 million years.

The Architecture

37 organ nodes are placed in 3D space using vertex-sampled coordinates from a real GLB anatomical mesh — positions derived from the actual model geometry, not hardcoded guesses. Each node belongs to one of 8 categories: Logic, Power, Thermal, Digestive, Sensory, Renal, Immune, Spirit.

The spinal column is auto-traced at runtime using a y-band bucketing algorithm across the mesh's vertex data. 24 vertebral disc markers (C2 through S2) are placed along that traced geometry and color-coded by the organ system they innervate.

Bidirectional Highlighting

Hovering any organ node illuminates its spinal bus lanes — the disc markers for the vertebral levels that innervate that organ system light up with its category color. Hovering any disc illuminates the organ nodes it innervates in return. The signal flows both ways, the way nerve conduction actually does.

This is implemented through a single hoveredCategory state in Scene that both OrganNode and SpinalCord consume simultaneously — no prop drilling maze, no global store.

View Modes

Logic — the neural network. Processing, memory, signal. Power — the circulatory grid, with two energy orbs traveling the full body circuit and the heart radiating expanding rings on each pass. Unified — all systems simultaneously.

The source of this project's philosophy is Federico Faggin's observation: we did not invent the computer. We remembered it.

What's in It

37 Organ Nodes

Every major organ mapped to a hardware analog across 8 categories. Positions sampled from GLB mesh vertex data — no hardcoded coordinates.

Auto-Traced Spine

Vertebral column geometry sampled directly from the GLB mesh at runtime using vertex filtering and y-band bucketing. 24 disc markers placed along the real anatomical curve.

Bidirectional Highlighting

Hover an organ — its spinal bus lanes light up. Hover a disc — its innervated organs glow. Category color propagates across both directions simultaneously.

Traveling Circulation Orbs

Two energy nodes circuit the full body on closed loops. The heart node radiates expanding rings on each pass — a clock cycle distributing power to the network.

Organ + Disc Modals

Clicking any node opens a glassmorphism panel with biological function, hardware analog, synthesis, and spinal bus lane assignment. Disc clicks show level, innervation target, and PCIe lane analogy.

Three View Modes

Logic (neural network), Power (circulatory grid with live animation), Unified (all systems). Each mode selectively renders its subsystems.
