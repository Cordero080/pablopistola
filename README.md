# Pablo Cordero Portfolio

Personal portfolio website showcasing software engineering projects, art, and creative work.

## Tech Stack

- HTML5, CSS3, JavaScript
- Three.js for 3D graphics
- Custom GLSL shaders
- Web Audio API

## Projects Featured

- **Numeneon** — Cyberpunk social media platform
- **Pneuma** — AI personality engine with philosophical archetypes
- **Transcendence** — 3D virtual pet game
- **Nexus Geom Lab** — Interactive 3D geometry platform
- **Dojo** — Martial arts training tracker
